# Data science portfolio

Portfolio for WEI ZIQIN, created for CISC7204 Practice 09.

- Website entry file: `index.md` in the repository root.
- Layout: self-contained HTML/CSS in the root Markdown entry (`layout: null`).
- Figures: two root-level PNGs, copied from the reproducible project outputs.
- Project repository: https://github.com/crudeboywei-cyber/data-science-project
- Intended Pages address: https://crudeboywei-cyber.github.io/data-science-portfolio/

## GitHub Pages publishing settings

In **Settings → Pages → Build and deployment**, select **Deploy from a branch**,
choose **main** and **/ (root)**, then save. This is a Markdown/Jekyll site;
do not add `.nojekyll`, because `index.md` needs Jekyll processing.

The intended URL above is not a deployment-status assertion. Verify that the
page actually returns successfully, images load, and project/source links work
after the Pages build completes. Official instructions:
https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Data and assistance

README. No account credentials, student ID or API keys are required to build
this website. Only the public-facing name requested by the assignment is shown.
